## 🔧 How to Update

1. Edit `index.html` directly on GitHub (click the pencil ✏️ icon)
2. Or clone the repo, make changes, and push:

```bash
git clone https://github.com/ChhunKuySreng/ChhunKuySreng.github.io.git
cd ChhunKuySreng.github.io
# make your changes
git add .
git commit -m "Update portfolio"
git push
```

3. GitHub Pages will auto-deploy within **~1 minute** ⚡
